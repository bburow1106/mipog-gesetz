# Mittagspointengesetz (MiPoG)

Gesetz über Pointen und wohlwollende Frotzeleien am Mittagstisch, das sich eine Tischrunde gegeben hat. Dieses Repository ist das Gesetzblatt.

- Geltende Fassung: [`gesetz/mipog.md`](gesetz/mipog.md); frühere Fassungen unter [`gesetz/fassungen/`](gesetz/fassungen/); Chronik in [`gesetz/chronik.yml`](gesetz/chronik.yml)
- Entstehung: `git log -p gesetz/mipog.md`
- Mitwirken: [`CONTRIBUTING.md`](CONTRIBUTING.md) (Antrag, Entwurf, Beschluss nach § 30, Verkündung)
- Beitritt anderer Tische: Issue „Beitrittserklärung“; Liste in [`gesetz/vertragsstaaten.yml`](gesetz/vertragsstaaten.yml)
- Webseite mit Volltext, Punkterechner und Punktewart-App: <https://mipog.de>

Tischgeheimnis (§ 3a MiPoG): Hier stehen keine Namen von Mitgliedern und nichts, was am Tisch gesagt wurde.
